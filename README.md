# Simulacro Cirugía Integral II 🪡

Práctica con 1.000 preguntas organizadas por capítulos, pautas explicativas y apoyos visuales.

## Publicación

GitHub Pages publica la rama `main`, carpeta raíz. Cada actualización confirmada en esa rama vuelve a publicar la página.

`index.html` y `assets/` forman la versión web. Las fuentes y los créditos del material de referencia aparecen dentro de cada pauta. No se atribuye una licencia única a recursos de terceros.

Para mantener la versión web desde el HTML autónomo, se separan sus imágenes en archivos con nombres derivados de su contenido. Los archivos que no cambian conservan su dirección y aprovechan la caché del navegador.
